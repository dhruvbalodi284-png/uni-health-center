# Security

This project is a static front-end. Bookings and staff accounts live in each
visitor's browser (`localStorage`), and the default admin login is visible in
the source code.

**Do not store real patient data with this setup.** Move login and data to a
real backend (for example Firebase or Supabase) before production use.

To report a security concern, open a private message to the repo owner instead
of a public issue.
